# Tréning Pytagoriády

Zbierka úloh z minulých ročníkov matematickej súťaže Pytagoriáda (kategórie P6–P8, od 2009/2010)
na samostatný tréning: filtrovanie podľa kategórie, kola, roka a témy, kontrola odpovedí,
osobný pokrok, kvíz „Uhádni trik“ a tvorba pracovných listov.

Zadania úloh pochádzajú z verejne dostupných materiálov Pytagoriády (NIVAM, nivam.sk).
Pokrok a meno žiaka sa ukladajú len v jeho prehliadači, nikam sa neposielajú.
